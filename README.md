# Прослави

Андроид апликација за организирање свадби и други прослави (веридби, крштевки, родендени, јубилеи).

## Можности

- **Прослави** – повеќе настани со датум, место, буџет и одбројување до денот.
- **Гости** – список со број на лица, страна (невеста/младоженец), маса и одговор (доаѓа / не доаѓа / чека). Одговорот се менува со еден допир, а списокот може да се сподели (Viber, e-mail…).
- **Буџет** – трошоци со цена и платено; цените на добавувачите автоматски влегуваат во вкупното.
- **Задачи** – готова листа за свадба со рокови пресметани од датумот, плус ваши задачи.
- **Добавувачи** – ресторан, фотограф, музика… со цена, капар и директен повик.
- **Распоред** – тек на денот по часови (готов предлог за македонска свадба).

Сите податоци се чуваат локално на телефонот (Room/SQLite), без интернет и без сметка.

## Градење

Kotlin, Jetpack Compose, Material 3, Room. minSdk 26 (Android 8.0).

```
./gradlew assembleDebug
```

Или отворете ја папката во Android Studio и стартувајте. GitHub Actions го гради APK-то при секој push (Actions → Build APK → Artifacts).
